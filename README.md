# RPYDict — Ren'Py Dialogue Dictionary

[简体中文](README.zh-CN.md)

Put `rpy-dict.rpy` in your Ren'Py project's `game/` folder. Put a SQLite dictionary in `game/rpydict/` (create the folder if needed). You can [download the OpenLeaf Dictionary](https://huggingface.co/datasets/BlazingCerulean/OpenLeaf-Dictionary/blob/main/openleaf-dictionary.db) as an example. During dialogue, a translucent `D` icon appears at the top-left. Click it to choose a word, or tap a dialogue word directly.
