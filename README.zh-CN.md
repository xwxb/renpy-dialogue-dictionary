# RPYDict — Ren'Py 对话词典

[English](README.md)

将 `rpy-dict.rpy` 放入 Ren'Py 项目的 `game/` 文件夹。将 SQLite 词典放入 `game/rpydict/`（没有该文件夹就新建）。可以下载 [OpenLeaf Dictionary](https://huggingface.co/datasets/BlazingCerulean/OpenLeaf-Dictionary/blob/main/openleaf-dictionary.db) 作为示例。对话时左上角会出现半透明的 `D` 图标，点击后选择单词查询；也可直接点击对话中的单词。
